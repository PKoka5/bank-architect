# Ranged and Magic: primary-slot review

Development policy, 25 October 2026. This is a bank-navigation progression,
not a purchase guide or universal DPS ranking. Actual owned items and
placeholders only. Personal item choices and saved blueprints keep priority.

Within a reviewed comparable group, actual RuneLite stats decide: Ranged
Strength / Magic damage first, accuracy next, then Prayer and defence. The
following sequences explain the broad progression and reviewed fallback when
stats are missing; close alternatives can change order through their real stats.
Colour/ornament versions with the same function use the same preference.

## Ranged

| Slot | Broad early → late progression |
|---|---|
| Head | Leather cowl → Coif → Snakeskin → Archer/Spined → blessed/Karil/Hueycoatl → Eclipse/Robin/3rd age/Crystal → Armadyl → Masori |
| Body/legs | Leather → Studded/Snakeskin → green → blue → red/mixed hide → black/blessed/Hueycoatl/Karil → Crystal/Armadyl → Masori |
| Cape | Ava's attractor → accumulator → assembler / Masori assembler → Dizana's quiver |
| Neck | Power/Glory/Fury → Necklace of Fangs → Anguish → Rupture |
| Hands | Leather → Snakeskin → coloured d'hide/blessed → Barrows gloves → Zaryte vambraces |
| Boots | Snakeskin / mixed hide → blessed / Ranger → Pegasian → applicable Avernic treads upgrades |
| Offhand | D'hide shields / Unholy book → Book of law → Odium ward → Dragonfire ward → Twisted buckler |
| Ring | Archers ring → imbued Archers ring → Venator ring; applicable shared offensive rings compete on raw stats |

The active weapon changes the armour context: Crystal pieces accompany active
Bowfa or Crystal bow. Masori normally leads with Twisted bow. Partial Crystal
sets retain only their owned pieces' relationship; no missing pieces are made up.

The general weapon bands lead with Twisted bow, Ascension crossbows, Bowfa,
Zaryte crossbow and Toxic blowpipe. Dragon hunter, Venator, Scorching and
Wilderness bows retain their separate functions; target effects are not assumed.
Earlier choices include Dragon/Armadyl/Rune crossbows, Hunters' sunlight
crossbow, Karil's crossbow, magic shortbows and the ordinary shortbow tiers.
Their reviewed navigation order does not claim one always out-damages another.
Ascension crossbows, bows and blowpipes use both hands; ordinary compatible
crossbows can place an offhand in the primary column.

## Magic

| Slot | Broad early → late progression |

| Hands | Mystic / bark alternatives → Infinity / available shared gloves → Tormented bracelet / Confliction gauntlets |

| Offhand | Broodoo / elemental tomes → Book of darkness → Malediction / Arcane / Ancient wyvern / Mage's book → Elidinis' ward / fortified ward, according to real damage and accuracy |
| Ring | Beacon / Seers ring → imbued Seers ring → Magus ring; applicable shared offensive rings compete on raw stats |

The general powered-weapon bands are usable Shadow → Eye of Ayak → Sanguinesti
→ Swamp trident → Seas trident, with Warped sceptre and Iban's staff among earlier
options. These are **best → earlier**, unlike the armour rows above. Casting
alternatives such as Kodai, Ancient sceptres, Nightmare, elemental and demonbane
weapons retain their roles. Shadow and Zorya's tome use both hands; usable
one-handed alternatives can retain an offhand. Zorya's tome is a special-attack
fallback rather than a claim that it beats Eye of Ayak's ordinary attacks.

## Boundaries

Slayer helmets, Void, Virtus, Crystal, elemental tomes, Confliction gauntlets and
specialist weapons keep their actual conditions. Raw equipment stats do not
silently include a Slayer assignment, spellbook, target, set bonus or special
attack. A single Fury or pair of shared gloves has one bank position, with the
existing Melee-first allocation. Better gear being withdrawn to an active-ID
placeholder does not make its uncharged counterpart usable.

The exact IDs, excluded states, family compiler, evidence and source limits are
in [the research directory](../../tools/research/ranged-magic-bis/README.md).
These lists do not add Alch eligibility or remove equipment from the bank.
