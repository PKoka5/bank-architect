# Alch: shared owned-upgrade rules and separate tag

Local build only; no commit, push or Plugin Hub update was requested.

## Shared Main and Ironman rule

Both presets enable **Gather outclassed gear** by default. A reviewed exact item ID from
the existing original alch-candidate list may become an Alch candidate when:

- Its local High Alchemy value is positive, and it is a real non-placeholder
  combat item with equipment stats.
- A real item currently in the bank has the same equipment slot and combat
  style, and proves a replacement: higher reviewed progression stage for armour,
  or full stat dominance. A weighted score alone is insufficient.
- Known quest, utility, skilling, god/prayer or special-attack roles do not require
  retaining it. The owner's later shared policy allows **clue-required alone**
  on ordinary reviewed gear to move to Alch once upgraded in either preset.

The shared proof replaces Ironman's old duplicate-stock shortcut. One hundred
copies of the best owned Rune/black d'hide item remain Combat as one bank stack.
Weapons cannot use higher stage alone: full stat dominance must prove them
replaceable, and known special-attack weapons remain protected apart from the
explicit exact Dragon halberd exception.
The later owner-approved exact Dragon halberd exception and med-helm/chainbody
feedback are documented in `alch-feedback-2026-10-06.md`.

| Bank contents | Shared result |
| --- | --- |
| Rune set is best owned gear | Combat, including duplicate stacks |
| Bandos body/tassets + Rune body/legs | Rune body/legs become Alch candidates |
| Bandos body/tassets + Rune helm/shield without their own upgrades | Helm/shield remain Combat |
| Black d'hide is best owned ranged gear | Combat |
| Blessed d'hide, Karil, Armadyl or Masori replaces the corresponding black d'hide slot | Reviewed obsolete piece may move to Alch |
| Only a placeholder, unknown stats or no positive alch value | No automatic Alch move |
| Better item removed from bank | The old item is reconsidered as Combat |
| Explicit personal Combat or Alch assignment | The personal assignment wins |
| Captured physical bank destinations | Saved destinations remain authoritative |

Only bank items are compared. Place upgrades in the bank before analysing;
inventory and equipped items are not read.

## Tags, customs and compatibility

The separate **Alch** tag starts beside **Slayer & Boss Loot**, and can be moved to
another destination in Tab Layout. Older saved plans lacking the new tag inherit
their existing loot destination; explicit saved Alch destinations are retained.
Manual assignment to Alch is also available in the bank assignment menu and
blueprint editor.

The checkbox is visible for both presets. Existing customs preserve their stored
checkbox setting, including Off. Editing a bundled preset creates a custom as
before. Both presets automatically give their selected alch candidates the
**Alch** tag and use the same ownership proof, role guards and conservative
fallback for unreviewed duplicates. The later feedback extends reviewed stock
IDs and makes the ordinary Dragon halberd always Alch;
see `alch-feedback-2026-10-06.md` for the precise rules.
Ironman's default Alch destination remains beside Slayer & Boss Loot, and an
older saved layout retains its existing loot destination. Moving only the Alch
tag moves these candidates independently of ordinary loot. Personal item
assignments and captured destinations still take precedence.

## Reviewed evidence

The original exact tier catalog already identifies Rune armour as stage 2,
black d'hide as stage 3, and Bandos/blessed d'hide/Karil as stage 4. Alch adds exact
replacement-stage entries for Armadyl armour (11826/11828/11830, stage 4) and
unfortified Masori (27226/27229/27232, stage 5), plus missing ordinary med-helm
and chainbody stages, without altering the shared gear
sorter's tier data. Those item IDs/names also exist in the checked-in RuneLite
gameval registry. These stages are our placement policy, not a claim that every
stat is strictly higher. The stat-dominance alternative uses actual RuneLite
equipment vectors.

Wiki sources were checked for item roles and grouping facts:
[Armadyl armour](https://oldschool.runescape.wiki/w/Armadyl_armour),
[Rune equipment](https://oldschool.runescape.wiki/w/Rune_equipment),
[elite clue item requirements](https://oldschool.runescape.wiki/w/Treasure_Trails/Full_guide/Elite).
Several direct item-page fetches were denied by the Wiki's robots policy; search
extracts and existing exact-ID data were used. No third-party plugin code,
resources or layouts were imported.
